A team of five does not need a tool for every job title it might hire later. Each extra system is another place a decision can hide.

## Four layers

| Layer | Examples | Rule |
| --- | --- | --- |
| Talk | One chat | Decisions that matter get copied to the doc |
| Docs | One wiki or drive | This is the system of record |
| Tasks | One board | If it is not on the board, it is not committed |
| Build | Repo, CI, deploy | Secrets stay here, not in chat |

Automation and AI sit on top of these. They do not replace the system of record. A bot that posts into a channel nobody reads is not a process.

## Three hard rules

1. Name an owner for every system. If nobody will watch it, do not adopt it.
2. New tools need a repeated job they shorten. "It looks modern" is not a job.
3. When someone leaves, you can revoke access from a list, not from memory.

Review the list twice a year. Remove a tool that only one person opened, unless that person is the owner of a real job. Personal note apps can stay personal. The team’s decisions cannot.

If the next addition is an automation platform, compare hosted and self-hosted options in [Make or n8n](/en/posts/make-vs-n8n/) before you add a server nobody wants to patch.
