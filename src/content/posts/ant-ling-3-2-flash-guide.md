## 这两周怎么试

样本从你有权使用、一天内能由人判断对错的工作里抽。每份同时交给现在的主力模型和 Ling-3.2-flash。输入保持同一份，并且去掉客户姓名、未公开报价、账号和密钥。记录表固定六列：日期、任务、模型名、人是否采纳、返工分钟、账单金额。免费窗口里金额如果是 0，写 0，并注明「两周促销，以当日账单为准」。一周结束只留一个变化。看图、短视频、长文档，哪一类采纳更高而且返工没有变长，就把那一类留在试跑名单里；另一类回到原来的模型。两个一起换，就分不清差别来自哪里。

### 先建密钥，再打一次文本

准备文档的顺序是：打开 API 控制台注册或登录，点击 Create Token 拿到密钥，把密钥放进环境变量，不要写进仓库和提示词。文档推荐的两行是：

```bash
export OPENAI_BASE_URL=https://api.ant-ling.com/v1
export OPENAI_API_KEY=<YOUR_API_KEY>
```

需要充值时，准备文档指向支付宝小程序云。定价页把绑定个人支付宝、开通百灵模型服务写在首次使用之前。两周免费期间要不要先充值，页面没有写最低金额。先绑定，看控制台是否允许在余额为 0 时调用。原价还没公布之前，不要为了试一次充一笔无法复算的钱。

OpenAI 兼容接口的地址是 `POST https://api.ant-ling.com/v1/chat/completions`。模型 ID 按文档写 `Ling-3.2-flash`，大小写与文档一致。非流式调用的超时是 90 秒，更长的生成把 `stream` 设为 true。`thinking.type` 对 3.0、3.1、3.2 系列都适用，默认 `enabled`，要更快可以设为 `disabled`。文档没有公布两档相差多少 token。第一次只求打通，用默认即可，并把返回里的 usage 抄进记录表。

```bash
curl --request POST \
  --url https://api.ant-ling.com/v1/chat/completions \
  --header 'Authorization: Bearer <YOUR_API_KEY>' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "Ling-3.2-flash",
    "stream": true,
    "messages": [
      {"role": "user", "content": "用三句话说明你能处理的输入类型"}
    ]
  }'
```

上面的问句是试通专用。文档自己的示例问的是大模型行业的机会与挑战。你换成一句不含客户信息的短问题即可，字段和地址不要改。

Anthropic 兼容接口的地址是 `POST https://api.ant-ling.com/anthropic/v1/messages`。身份验证用 `Authorization: Bearer` 或 `x-api-key`，两者恰好保留一个。Python 和 Node SDK 示例里的 `base_url` / `baseURL` 是 `https://api.ant-ling.com/anthropic`，不要把末尾的 `/v1/messages` 再拼进 SDK 的 base。`max_tokens` 的接口默认值是 32000，SDK 示例用的是 1024。第一次试通用 1024，避免一次就拉满默认上限。模型名同样是 `Ling-3.2-flash`。

已经在用 OpenAI 或 Anthropic SDK 的项目，只改 base URL、密钥和模型名，先打通这一次文本，再接图片。不要在同一天把生产路由从现有模型切过来。

### 图、短视频和长文档各留一份

多模态教程开篇同时覆盖 Ling-3.2-flash 和 Ling-3.0-flash-VL。限制写在教程正文里；文中的 curl 示例仍把 `model` 印成 `Ling-3.0-flash-VL`。测 3.2 时改模型名，块结构沿用同一页。

图像只接受 Base64。格式是 JPEG 或 PNG。单张不超过 `16384 * 784` 像素，单张 Base64 不超过 32 MiB，单次请求最多 40 张，整个请求体最大 32 MiB。OpenAI 兼容的块是 `image_url`，URL 形如 `data:image/jpeg;base64,<数据>` 或 `data:image/png;base64,<数据>`。Anthropic 兼容的块是 `type: image`，`source.type` 为 `base64`，并带上 `media_type` 和 `data`。教程写明 OpenAI 侧的 `image_url.detail` 不受支持，引擎按 default 处理，不要自己加这个字段。先发一张你有权使用的图表或海报。成功标准写成一句：图里的数字和结构有没有进回答，有没有多出图里不存在的数。

视频也只接受 Base64。格式是 MP4、MOV、WMV。时长不超过 30 秒，单条 Base64 不超过 32 MiB，一次请求只放 1 条。抽帧固定 2fps，每个视频最多 32 帧。30 秒按 2fps 会超过 32 帧，采样会被这个上限截住，所以第一段用明显短于 30 秒的片子。OpenAI 兼容用 `video_url`，前缀同样是 `data:{MIME_TYPE};base64,`，MIME 按文件实际类型填，教程没有把某一种 video MIME 写成唯一合法值。Anthropic 文档写 Ling-3.2-flash 的 Messages 接口接受文本、图像和视频，但视频那一节没有给出 Anthropic 的 content 块示例。短视频试跑先走 OpenAI 兼容接口。成功标准是：回答是否说中你回放能核对的画面。文档没有写这个接口会生成一条新视频。

音频不是这条模型的输入。教程里的语音理解属于 `Ming-3.0-audio-flash`，格式和块类型都不同。不要把一段录音塞进 Ling-3.2-flash 再按多模态成功来记。

长文档用一份你能回原文核对的材料，问三个问题，例如金额、日期、负责人。成功标准是三问里答错几问、人要返工几分钟。上下文上限是 1M，按定价页的通常换算大约相当于 50 万汉字这一量级，仍然先用一篇你读得完的文档，不要第一天把整月归档一次塞进去。`enable_search` 默认关闭，打开后会增加 token。看图和核对原文这两周先保持关闭，否则你分不清是模型读了材料，还是搜索补了一句。

3D 在模型页写成理解三维场景和空间关系、支持相关交互。验收用一张你能核对前后、左右和遮挡的场景照片，看回答有没有把空间关系说反。文档没有写 API 会返回一份三维模型文件。不要在这两周把三维交付写进客户工期。

### 长程 Agent 只试一条不写出站的工具

两套接口都有工具调用。OpenAI 兼容用 `tools`，Anthropic 兼容另外有 `tool_choice`。模型页把多模态长程 Agent 写成卖点：多步任务里保持目标，并基于多模态信息做决定。这是能力说明，不是你的任务通过率。

这两周只加一条只读工具，材料用公开或脱敏数据。工具不要连接付款、对外发送、改权限或生产数据库。模型可以起草，发送和付款仍由人确认。默认思考是开着的。屏幕上很短的一段工具参数，不代表 usage 里的输出 token 很少。免费窗口把每次的 prompt 和 completion 记下来，促销结束、单价公布之后，才能用这列数字估常驻成本。

## 常见问题

### 现在就能下载 Ling-3.2-flash 的权重吗？

不能。2026 年 11 月 6 日打开的更新日志和模型页都没有给出这一款的仓库地址。模型页写明已在 Hugging Face 和 ModelScope 开源的是 Ling-3.0-flash-VL，规模是 124B 总参数、5.5B 激活、256K 上下文。这周做聊天界面和 API 试跑。

### 两周免费结束之后，一次调用多少钱？

还不能算。定价页写上线前两周免费、结束后恢复原价，人民币表和 OpenRouter、ZenMux 的美元表都没有 Ling-3.2-flash。同页 3.1 的输入是 2 元划到 0.50 元，OpenRouter 上是 0.30 美元划到 0.075 美元。这些格子属于 3.1。免费窗口从 11 月 5 日算起大约到 11 月 19 日前后，页面没有钟点。

### 榜单分数和网上的 0.30 美元能当选型依据吗？

不能。官方更新日志、模型页和 TechNode 的报道都没有给出可核对的独立分数。转述里对照 Claude Opus 5 的成绩，包括 OmniDocBench 一类名字，按官方自测或二手转述处理。0.30 美元是 3.1 在 OpenRouter 表上的划线输入价。

### 这两周适合拿它做什么？医疗和客户材料能上传吗？

用脱敏材料试一张图、一段短于 30 秒的视频、一份能核对的长文档，以及一次不触碰付款和发送的工具调用。医疗多模态是协助分析的能力说明，不是临床器械。客户个人信息、合同、未公开数字和密钥不要进入免费试跑。
